# Summary Library

פרויקט גמר בקורס Front-End – מערכת שיתופית לניהול סיכומי שיעורים עבור סטודנטים.

</p>

<p dir="rtl">

## תיאור הפרויקט

Summary Library היא מערכת אינטרנטית המיועדת לסטודנטים, המאפשרת חיפוש, ניהול והעלאת סיכומי שיעורים לפי קורסים.  
המערכת פותחה כדי לספק פתרון יעיל לניהול ידע לימודי, עם דגש על חוויית משתמש נוחה, עיצוב רספונסיבי ונגישות מכל מכשיר.

</p>

<p dir="rtl">

## יכולות עיקריות

- חיפוש סיכומים לפי קורסים  
- טופס ידידותי להעלאת סיכומים  
- לוח בקרה אישי לניהול הסיכומים שהמשתמש העלה  
- ממשק ניהול (Admin Panel) לאישור, עריכה ומחיקה של סיכומים  
- דף עזרה והגדרות עם תמיכה טכנית  
- שליחת מייל אוטומטית למשתמש חדש בעת הרשמה באמצעות EmailJS  
- התאמה מלאה לדסקטופ, מובייל וטאבלט

</p>

<p dir="rtl">

## טכנולוגיות בשימוש

- React – לפיתוח ממשק משתמש  
- React Router DOM – ניתוב בין דפים  
- Firebase – ניהול משתמשים, מסד נתונים ואחסון קבצים  
- TailwindCSS – עיצוב מודרני אחיד  
- Recharts – הצגת נתונים סטטיסטיים בגרפים  
- EmailJS – שליחת מיילים אוטומטית בהרשמה

</p>

<p dir="rtl">

## מבנה הפרויקט

- `App.jsx` – קובץ ראשי הכולל את הגדרת הנתיבים (Routes) של האפליקציה  
- `Navbar.jsx` – סרגל ניווט קבוע המופיע בכל עמוד  
- `components/` – קומפוננטים חוזרים  
- `pages/` – דפי מערכת: Home, Courses, Upload, Dashboard, Admin, Help  
- `docs/` – שרטוטים (Wireframes), תסריטי שימוש ותיעוד

</p>
